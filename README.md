# 吳・古本取名

取名遊戲，全部用字取自**古本八部**：古本易經、古本紫微斗數、古本山海經、古本神農本草、
古本道德經、古本抱樸子、古本詩經、古本楚辭。
姓固定「吳」，名一至二字。**喜用神只有木、火** —— 木為喜用、火為次用。

[線上玩](https://alastorid.github.io/wubaobao/)

## 喜用神：木、火

原局木弱，火雖有而不得令。所以：

- **木是喜用，首選**，約佔取名用字的七成。
- **火是次用，輔助**，約佔三成 —— 火有用，但不狂補。
- 介面只有「木火（七三之序）／木／火」三個選項，**沒有金、水、土**。
- 隨機取名時每個字各自按木七火三抽；兩個字都是木的機率約五成，
  火火只約一成，符合「喜木、不狂補火」。

## 玩法

**六爻成卦。** 卦盤只有六條爻線，點任何地方或滑過去都會擲下一爻
（少陰 ⚋ / 少陽 ⚊），並從當前古本抽一個字收進「所收之字」。
**擲滿六爻必定成卦，必定得一個名字**，卦盤自動歸零重新起卦。

八部古本共用同一副卦盤，只是成卦後顯出的經文與抽字來源不同：

| 古本 | 成卦後顯示 | 取字來源 |
| --- | --- | --- |
| 古本易經 | 六十四卦卦名、卦辭、大象傳 | 卦名、彖傳、象傳、大象傳用字 |
| 古本紫微斗數 | 命宮、十四主星、四化、神曜 | 主星名、宮位名、十二神 |
| 古本山海經 | 山海篇目與所載之物 | 山海草木、靈鳥異獸 |
| 古本神農本草 | 出處、歸經、性味、功用 | 經方本草藥名 |
| 古本道德經 | 依六爻定章，得章名與經文 | 樸、儉、慈、若、赤子、赤 |
| 古本抱樸子 | 依六爻定篇，得篇旨與作者 | 煉、壽、誠、忠 |
| 古本詩經 | 依六爻定篇，得風雅頌名句 | 采、佩、蕙、靜、楚、葛、巧、灼、姝、愛、倩 |
| 古本楚辭 | 依六爻定篇，得離騷九歌名句 | 蘭、茝、芳、杜、薜、荔、椒、曼、懷 |

名字會附上每個字的**筆畫、出處與起名寓意**，例如：

> 吳仁容
> 仁 · 4畫 · 古本易經 坤·象 · 厚德仁愛
> 容 · 10畫 · 古本易經 師·象 · 容民畜眾

## 複製名單

名錄開頭有三顆複製鈕，方便把名單貼給老師或命理師，讓人從中挑出
更有 context 的名字：

| 按鈕 | 內容 |
| --- | --- |
| **只複製名字** | 一行一個名字，最乾淨，直接貼出去問 |
| **複製含出處** | 名字 + 拼音 + 五行 + 逐字筆畫與典據 |
| **複製全部** | 加上序號與完整欄位，給需要完整脈絡的人 |

每一列右邊也有「複製」，只複製那一個名字及其出處。

「複製含出處」長這樣：

```
吳果茹　guǒ rú　木 · 木
　果（8畫・古本易經 蒙·象・果決有擔當） 茹（9畫・古本易經 泰·初九・茹茅同心）
成卦：噬嗑
```

走 `navigator.clipboard`；不可用時退回 `execCommand('copy')`
（iPad Safari 常需要）。兩種都失敗會提示請手動選取，不會靜默無反應。
名單清空後複製列自動隱藏。

## 字庫

243 個取名用字，**全部只屬木、火兩行**，零重複。

| | 木 | 火 |
| --- | --- | --- |
| 古本易經 | 45 | 30 |
| 古本紫微斗數 | 9 | 29 |
| 古本山海經 | 10 | 10 |
| 古本神農本草 | 71 | 6 |
| 古本道德經 | 5 | 5 |
| 古本抱樸子 | 1 | 3 |
| 古本詩經 | 5 | 5 |
| 古本楚辭 | 6 | 3 |
| **合計** | **152** | **91** |

每個字附：`c` 繁體字、`p` 拼音、`s` 繁體筆畫、`w` 五行、
`book` 出處古本、`cite` 書中出處、`meaning` 起名寓意。

- 出處是**取名用典索引**，標明該字取自哪一部、哪一篇，不代表字只見於該處。
- 五行歸屬各姓名學派別有出入，本庫提供固定分類供遊戲使用：
  部首／意象 —— 木、禾、艹、竹、亻、羊 → 木；火、日、心、扌、宀 → 火。
- 拼音與筆畫核對 Unicode 17.0 Unihan，筆畫用繁體字 `kTotalStrokes`，多值採後值。
- 起名寓意是給孩子的祝願，並非字典完整釋義。
- **抱樸子只有 4 字**：這部書偏金丹方技，可用的木火取名字彙本來就少，
  沒有為了湊數而硬塞。選抱樸子時，若湊不出第二個字，
  `pickGivenName` 會自動放寬到全庫同一行 —— 名字絕不會抽不出來。

來源：[Unicode Unihan 說明](https://www.unicode.org/reports/tr38/)、
[Unicode 17.0 資料](https://www.unicode.org/Public/17.0.0/ucd/Unihan.zip)。
Unicode 資料授權見 `UNICODE-LICENSE.txt`。

## 禁用字

指定排除 29 字：`丞以品妍妤宇宥宸希彤恩承晨晴樂沁沐泓涵淇淳渝澄熙睿祐語霏霖`，
連帶排除 12 個近形近音字：`佑右辰曦琪祺純瑜愉橙叡晶`。

防護是自動的，會在三層生效：

1. **建字庫時過濾** —— 禁用字不會進入字庫。
2. **取名前檢查** —— 就算字庫被改壞，含禁用字的名字也不會寫進名錄。
3. **舊資料過濾** —— 讀名錄時會剔除含禁用字的舊條目。

**唯一例外：以／樂／語／宥。** 這四個字只出現在「原典逐字引用」裡：
大象傳的「君子以…」句式（64 卦中 59 卦都有）、需與豫的大象「宴樂」「作樂」、
頤的大象「言語」、解的大象「宥罪」。改字等於竄改經典，所以保留原文。
測試會明確檢查這四個字**只出現在經文區塊**，絕不當成取名字。

## 驗證

```sh
node tests/namepool.cjs          # 字庫、五行、禁用字、七三之序、六十四卦
# Playwright 僅供開發驗證，不是網站執行依賴：
npm install --prefix /tmp/wubaobao-qa playwright
node /tmp/wubaobao-qa/node_modules/playwright/cli.js install chromium webkit
NODE_PATH=/tmp/wubaobao-qa/node_modules ENGINE=chromium node tests/browser.cjs
NODE_PATH=/tmp/wubaobao-qa/node_modules ENGINE=webkit    node tests/browser.cjs
# 上線後同一套測試：
NODE_PATH=/tmp/wubaobao-qa/node_modules node tests/browser.cjs https://alastorid.github.io/wubaobao/
# 視覺檢查（各古本、各狀態、各尺寸的畫面）：
NODE_PATH=/tmp/wubaobao-qa/node_modules node tests/shots.cjs
```

`?qa` 啟用唯讀狀態快照，測試仍使用真實觸控與滑鼠操作。

- `tests/namepool.cjs` — 243 字零重複、只屬木火、每部古本都有字、
  禁用字三重防護、六十四卦卦序與爻象互異自洽、道德經章號不重複且在 1..81、
  抱樸子／詩經／楚辭篇目齊全且經文無禁用字、七三之序抽樣 6,000 次、20,000 次取名不重字不越行。
  古本清單由 `SOURCES` 推導，日後增刪古本不必改測試。
- `tests/browser.cjs`（`tests/tiles.cjs` 為實作）— 六種尺寸無溢出、
  擲滿六爻必成名、密集操作不卡死、滑動也能擲爻、每部古本都能成卦且經文面板有內容、
  喜用神只出木火、指定木不得混火、名錄 CRUD、**三種複製格式皆寫入剪貼簿且內容正確**、
  持久化與損壞資料回復、舊禁用名不得進入名錄、實際波形驗證音訊獨立靜音、
  全螢幕 fallback、畫面文案無禁用字、600 次擲爻的木火實測比例。
- `tests/soak.cjs` — iPad 尺寸長時間連續觸控量測；`SOAK_MS=20000` 可縮短。
- `tests/shots.cjs` — 產生視覺檢查用的畫面。

## 量測與限制

WebKit 模擬 iPad 820×1180 @2x，20 秒 2,002 次觸控、4,488 次擲爻：
平均 16.67ms／幀、p95 19ms、零錯誤，特效節點 90、音訊聲部 40 均為上限值。
Chromium 同長度測試平均 16.66ms／幀、p95 17.8ms。

以上為 Mac 上的瀏覽器與模擬尺寸，**不是實體 iPad 的 60fps 保證**。
網站是 DOM/CSS，沒有 WebGL，也沒有每幀碰撞迴圈；尊重減少動態效果設定。
桌面模擬尺寸與效能量測不代表實體 iPad 效能。
